Manual del Sitio Web

Guía sobre los elementos, animaciones, navegación y SEO del sitio.

1. Optimización para Motores de Búsqueda (SEO)

Para mejorar la visibilidad del sitio en buscadores como Google, se han implementado las siguientes técnicas de SEO:

  • Metaetiquetas Estratégicas: Cada página cuenta con títulos, descripciones e imágenes de vista previa para redes sociales.
  • Indexación y Rastreo: Se utilizan los archivos robots.txt y sitemap.xml para guiar a los motores de búsqueda.
  • Contenido Semántico y Accesible: El uso de HTML semántico y atributos alt en las imágenes beneficia tanto al SEO como a la accesibilidad.

Ejemplos de las metaetiquetas utilizadas.

<meta charset="utf-8">
<meta name="viewport" content="...">
<title>Conócenos — VSI</title>
<meta name="description" content="...">
<link rel="icon" href="favicon.ico">

2. Elementos y Tarjetas de Información

El sitio se basa en un sistema de tarjetas para presentar la información de forma modular y atractiva:

5. Animaciones

El sitio incorpora animaciones sutiles para guiar la atención del usuario y mejorar la experiencia de navegación:

  • Animación al Desplazar (Scroll): Los elementos aparecen gradualmente a medida que el usuario explora la página.
    • La clase .animate-on-scroll activa la animación.
    • Por defecto, los elementos aparecen desde abajo (efecto Fade In Up).
    • Las clases .animate-left y .animate-right controlan la aparición desde los costados.
  • Objetivo: Presentar el contenido de forma progresiva para crear una experiencia de descubrimiento agradable y evitar sobrecargar al usuario.

6. Navegación del Sitio

La navegación está diseñada para ser intuitiva y accesible. Se adapta automáticamente al tamaño del dispositivo.

Menú Principal

  • Menú de Escritorio: En pantallas grandes (más de 700px), el menú es una barra horizontal siempre visible, permitiendo un acceso rápido a las secciones principales.
  • Menú Móvil: En dispositivos móviles, el menú se colapsa en un icono de "hamburguesa". Al tocarlo, se despliega una lista vertical con las opciones de navegación, optimizando el espacio en pantalla.
  • Pie de Página: Funciona como un centro de navegación secundario, con enlaces a redes sociales, datos de contacto y este manual.
