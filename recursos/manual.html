Manual del Sitio Web

Guía sobre los elementos, animaciones, navegación y SEO del sitio.

1. Optimización para Motores de Búsqueda (SEO)

Para mejorar la visibilidad del sitio en buscadores como Google, se han implementado las siguientes técnicas de SEO:

  • Metaetiquetas Estratégicas: Cada página cuenta con:
    • <title>: Títulos únicos y descriptivos.
    • <meta name="description">: Resúmenes concisos del contenido.
    • <meta property="og:image">: Imágenes de vista previa para redes sociales.
  • Indexación y Rastreo:
    • robots.txt: Permite a los buscadores indexar todo el sitio y les indica la ubicación del mapa del sitio.
    • sitemap.xml: Lista todas las páginas importantes para asegurar que los motores de búsqueda las encuentren y rastreen eficientemente.
  • Contenido Semántico y Accesible:
    • Se utiliza HTML semántico (<header>, <main>, <section>) para estructurar el contenido, beneficiando tanto al SEO como a la accesibilidad.
    • Todas las imágenes incluyen el atributo alt con texto alternativo para describir su contenido a lectores de pantalla y motores de búsqueda.

3. Animaciones

El sitio incorpora animaciones sutiles para guiar la atención del usuario y mejorar la experiencia de navegación:

  • Animación al Desplazar (Scroll): Los elementos aparecen gradualmente a medida que el usuario explora la página.
    • La clase .animate-on-scroll activa la animación.
    • Por defecto, los elementos aparecen desde abajo (efecto Fade In Up).
    • Las clases .animate-left y .animate-right controlan la aparición desde los costados.
  • Objetivo: Presentar el contenido de forma progresiva para crear una experiencia de descubrimiento agradable y evitar sobrecargar al usuario.

4. Navegación del Sitio

La estructura de navegación está diseñada para ser intuitiva y accesible en todos los dispositivos:

  • Menú Principal: Contiene los enlaces clave (Inicio, Conócenos, Contacto). En dispositivos móviles, se convierte en un menú "hamburguesa" para optimizar el espacio.
  • Pie de Página: Funciona como un centro de navegación secundario, con enlaces a redes sociales, datos de contacto y este manual.

Botón "Volver Arriba"

Un botón flotante que aparece al hacer scroll, permitiendo al usuario regresar al inicio de la página con un solo clic. Es circular, con un ícono claro y un color de fondo que contrasta con el contenido.
